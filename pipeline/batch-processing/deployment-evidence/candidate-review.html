What verification established

The three observed defects are resolved. Tests cover both scientific modes, safe output naming, matching records, partial saves, cancellation races and cleanup. All 384 exact decoder comparisons passed. The independent 100-image, 24-megapixel run saved all 200 image and JSON files with no temporary files or cleanup debt left over.

The final settled footprint was 232 MB, below the three-image maximum of 350 MB. This measures settled memory for the tested run; it does not promise a universal peak bound for native decoders or file providers.

What remains unverified

  • Mac native UI automation, keyboard, VoiceOver and close/quit lifecycle coverage were blocked by the development environment.
  • Native acknowledgment of Cancel within one second is inconclusive.
  • Real cloud-provider behavior and every external crash and cleanup window remain unverified.
  • Physical-device behavior and installation of this TestFlight build belong to the user and testers. No device was accessed for this preparation.

Batch runs are foreground work. A mobile interruption stops the run without automatic resume. Provider synchronization is controlled by the selected provider.
